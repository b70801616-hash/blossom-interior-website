# Blossom Interior & Decorator Website

A modern, responsive website for Blossom Interior & Decorator - premium interior design and decoration services serving Kalyan, Dombivli, Thane, Mulund, Ghatkopar, and Navi Mumbai.

## Features

✨ **Modern Design System**
- Premium color palette (brass, moss green, warm paper tones)
- Responsive grid layouts
- Smooth animations and hover effects
- Mobile-optimized interface
- Accessibility features (focus states, semantic HTML)

🎯 **Key Sections**
- **Header** - Sticky navigation with quick action buttons
- **Hero** - Eye-catching introduction with CTAs and key metrics
- **Services** - 9 comprehensive services with detailed descriptions
- **Process** - 6-step workflow explaining project execution
- **Contact** - Multiple contact methods (phone, WhatsApp, form)
- **Areas Served** - Service coverage display
- **Footer** - Brand information and quick links
